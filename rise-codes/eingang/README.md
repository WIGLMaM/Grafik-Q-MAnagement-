# Eingang

Hier kommen die Original-Codes hin, die nach dem System umgebaut werden sollen. Sie werden nicht verändert und dienen als Referenz.

So geht's:
1. Codes (HTML-Dateien) in diesen Ordner legen, z. B. über GitHub hochladen, oder direkt in Claude Code anhängen bzw. einfügen.
2. In Claude Code schreiben: «Bitte die Codes im Eingang umbauen.»
3. Die fertigen Codes erscheinen in `rise-codes/codes/`.
